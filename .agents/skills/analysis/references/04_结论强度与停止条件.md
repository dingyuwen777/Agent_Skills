# 结论强度、表达与停止条件

## 1. 结论强度匹配证据

直接证据充分可以明确陈述；多条事实共同支持但仍有假设时写成高可信推断；只有局部迹象时写成可能解释或待验证假设；关键事实缺失时明确不能确定。

## 2. 先结论后依据

默认顺序：

```text
直接结论
→ 最关键原因
→ 推荐动作
→ 必要的限制 / 风险 / 未验证项
```

背景只在帮助理解时出现。

## 3. 控制篇幅

删除对用户问题的长篇复述、同一观点换词重复、不改变结论的边缘知识、为显示专业而堆的术语和框架、没有触发条件的未来清单。

用户明确要求详细、需要审计或问题确实复杂时可以展开，但每一部分都必须有独立信息价值。

## 4. 停止条件

核心问题已回答、推荐有依据、关键不确定性已标明、下一步可执行，且新增分析预计不会改变决策或风险等级时结束。不要为了“全面”继续扩展。
