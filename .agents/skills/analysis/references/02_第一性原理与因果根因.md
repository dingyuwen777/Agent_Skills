# 第一性原理与因果根因

## 第一性原理不是从零发明

把问题还原到不可省略的事实、约束和机制：目标是什么 → 哪些约束不可违反 → 哪些变量真正决定结果 → 当前系统为什么产生现象 → 哪些做法只是历史习惯/类比 → 最少改变什么。成熟经验仍可使用，但应能解释它解决了哪个真实机制。

## 因果判断

区分相关、机制、因果、共同原因和反向因果。重要因果结论至少检查替代解释、时间顺序、适用范围和**反事实**：假设原因不存在，结果是否仍可能发生？

## 根因分析

根因不是最底层组件，而是**在当前控制范围内，改变后能稳定消除或显著降低复发概率的原因**。按“症状 → 稳定事实 → 最近变化/正常参照 → 多个可证伪假设 → 最小实验 → 机制 → 修根因”推进。证据不足时给当前最可能假设和验证方法，不把推测写成已确认根因。
