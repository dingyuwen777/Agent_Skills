# 第一性原理与因果根因

## 1. 第一性原理的实际含义

把问题还原到足以解释结果的：

```text
目标
+ 不可绕过的约束
+ 关键机制
+ 可观察事实
+ 因果关系
```

不是把所有专业知识丢掉，也不是从最底层物理定律重新推导。

## 2. 因果分析

区分现象、直接触发因素、维持问题的机制、真正可改变结果的根因，以及只是同时出现但没有因果证据的相关因素。

多个原因都可能成立时，建立可证伪假设并说明什么证据能区分它们。

## 3. 根因而不是补丁

好的根因解释至少回答：为什么发生、为什么现在暴露、为什么现象与该机制一致、改变哪个变量能稳定消除问题、相邻症状是否由同一机制产生。

证据不足时写“最可能解释”而不是“根因已确认”。

## 4. 避免框架先行

MECE、SWOT、5 Whys、鱼骨图等只在能降低遗漏或提高可证伪性时使用。不要因为问题复杂就默认套框架。
