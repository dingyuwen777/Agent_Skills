# 复杂问题拆解与结论强度

## 按决策依赖拆

先明确最终需要回答的问题或决策目标，**不预设答案**；再向前追必须确认的事实、机制与判断。只有真正影响上层结论的项才进入拆解。没有依赖可并行，存在 blocker 按依赖顺序处理。

## Two-Pass Independent Analysis

当任务要求“全面分析、系统优化、全面排查、还有没有遗漏、是否已经最好”等**完整性判断**时，使用双遍独立分析；这是通用问题分析方法，不绑定软件工程或 Agent_Skills。

### Pass 1 — Goal-derived Independent Model

先暂时不把当前方案、已有实现、现行规则、现有测试、历史结论或本轮刚形成的答案当作分析边界，从真实目标重新推导：

```text
真实目标 / 成功与失败标准
→ 不可违反的约束
→ 决定结果的关键机制
→ 生命周期 / 状态变化
→ 主要失败模式
→ 负空间：当前问题表述没有覆盖什么
→ 高价值反例：什么事实最可能推翻当前判断
→ 二阶效应：自动机制会继续产生什么
→ Goal-derived Independent Model
```

第一遍的目标是摆脱当前答案的锚定，而不是枚举所有理论风险。只有与当前目标、必要机制或主要失败模式存在直接关系的维度进入模型。

### Pass 2 — Reality Mapping

再把第一遍得到的必要条件和失败模型映射到当前事实，逐项判断：

```text
已覆盖
部分覆盖
未覆盖
相互冲突
存在绕过路径
规则存在但证据不足
暂时未知
```

第二遍只把会实质改变当前结论、方案、完成判定或重大风险的 Gap 升级为后续调查项；其余不为了“全面感”继续展开。

## Counterexample Pass

在准备形成强结论前，对核心结论做一次**有界反证**：主动寻找最可能推翻该结论的高价值反例。

Counterexample Pass **不递归扩张**，也不是递归搜索：

```text
反例
→ 反例的反例
→ 更多理论反例
```

只检查会改变行动的主要反例。主要反例已处理、剩余理论可能不会改变决策时结束。

## Bounded Closure

全面分析必须同时满足停止约束；**Comprehensiveness ≠ Unbounded Exploration**。

### Decision-Relevance Gate

新增调查项只有同时满足以下条件才继续：

1. 与当前真实目标、必要机制或主要失败模式直接相关；
2. 不是已经由当前证据闭环的重复问题；
3. 不是只有抽象可能性、缺少当前可达触发或决策价值；
4. 不同答案会实质改变结论、方案、完成判定或重大风险；
5. 可以以合理成本取得有决策价值的 Evidence。

任一条件不成立，就停止扩展该分支。**问题本身不能因为还能继续问“为什么”而自动生成新的调查权限。**

### Material Information Gain

继续分析至少应能做到一项：

- 降低一个会影响行动的重要未知；
- 证伪一个重要假设；
- 区分两个会导向不同实际决策的方案；
- 确认一个会改变完成/风险判断的主要失败边界。

如果新的调查只增加描述、理论假设或问题数量，却不改变问题模型和行动，视为 **No Material Information Gain → STOP**。

### Closed Issue Reopen Guard

已经有足够证据闭环的问题，在没有**新事实、新失败、新独立风险或新 Requirement**时不得重新打开。发现“还能进一步优化”本身不是重新开启已闭环问题的理由；新的独立价值可以作为另一个问题评估，但不能递归吸回当前任务。

## 独立失效模式审计

“还有没有优化 / 全面排查 / 是否最好”不能从现有方案反推。第一遍独立模型应检查与当前目标有决策价值的**负空间**、可推翻结论的**反例**、自动机制的**二阶**派生，以及生命周期/权限/并发/失败恢复/跨模型宿主/成本和门禁盲区。禁止用当前实现、规则、测试或本轮结论做**循环证明**。

只有完成 Two-Pass、处理会改变行动的主要反例，并通过 Bounded Closure 后，才能说“在**已审计范围**内没有发现更多高价值缺口”，同时列出仍会影响行动的**未验证**边界。

## 控制分析深度

每深入一层都问：新信息会改变结论、推荐、风险或边界吗？能否合理成本取得？若不会改变行动，或已经没有 Material Information Gain，就停止。分析深度由问题复杂度决定，不由“希望多找几个问题”决定。

## 结论强度

确认 = 直接事实或高质量一致证据；高度支持 = 多条独立证据且主要替代解释已排除；倾向 = 方向一致但有重要未验证条件；可能 = 有合理机制但证据不足；未知 = 无法可靠判断。没有统计依据不随意给概率。

## 输出未确定性

只报告会影响行动的未确定性：缺什么、为什么重要、如何验证、验证前采用什么安全默认。
