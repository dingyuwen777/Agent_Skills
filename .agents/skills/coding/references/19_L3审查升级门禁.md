# L3 审查升级门禁

本 Reference 只承担 L3 路由升级：当任务已经确认达到 L3 时，把完成前两阶段复核所需 Coding 上下文加入 required Context。

它不新增第二套 Review 方法，也不改变 L3 风险定义。具体需求符合性、代码质量、验证、兼容、Migration、回滚和独立 Review 方法继续由现有 Completion、Review 与对应专业 Reference 负责。

普通 L1 / 轻量 L2 不因本 Reference 增加 Review 或 Completion 开销。
