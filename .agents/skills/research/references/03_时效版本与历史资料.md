# 时效、版本与历史资料

## 1. 默认找最新适用信息

除非用户明确要求历史、旧版或指定时间点，否则默认目标是：

```text
当前仍有效
+ 最新正式版本
+ 与用户对象 / 地区 / 环境适用
```

不要因为旧页面排名高就采用。

## 2. 区分四种时间

- 页面发布 / 更新时间；
- 事件实际发生时间；
- 数据统计区间；
- 规则 / 软件 / 产品版本生效时间。

回答“最新”时至少确认真正影响结论的时间维度。

## 3. 相对日期

用户说“今天、昨天、最近、本周”时，基于当前日期解释；如果用户明显混淆，使用绝对日期澄清。

## 4. 历史问题

用户明确要求旧资料时：固定目标时间点；优先找当时有效的原始资料；不用今天的版本覆盖历史状态；如需说明后续变化，把“当时事实”和“后来变化”分开。
