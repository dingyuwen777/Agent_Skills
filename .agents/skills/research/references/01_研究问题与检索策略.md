# 研究问题与检索策略

## 1. 先定义要证明什么

把请求拆成少量可验证问题：用户真正需要的答案、支撑答案必须确认的事实、不改变结论的背景信息，以及时间/地区/版本/对象范围。不要先搜一堆资料再反向决定问题。

## 2. 查询策略

优先从高信号查询开始：

```text
明确实体 / 标准 / 产品 / 公司
+ 关键事实
+ 必要时间或版本
+ 一手来源域（适用时）
```

结果不足时再扩展同义词、旧名/新名、官方术语、精确日期/版本、不同语言和已知关键来源。

## 3. 研究深度与问题匹配

单一当前事实不需要做“深度研究”；多实体比较、争议主题、行业综述或重大决策才扩大来源覆盖。先高价值事实，后背景。不要用搜索数量衡量质量。

## 4. 搜索结果不是证据本身

搜索摘要、聚合页和 AI 摘要主要用于发现来源。重要事实尽量打开原文并确认上下文、日期、版本和限定条件。
